The autoscroll rule

// Read BEFORE appending: once the node is in the tree the measurement
// has already changed. 24px of slack, because a trackpad rarely lands
// exactly on zero.
const atBottom = log.scrollHeight - log.scrollTop - log.clientHeight < 24;

log.append(entry);

if (atBottom) {
    log.scrollTop = log.scrollHeight;   // not scrollIntoView: that scrolls
    jumpBtn.hidden = true;              // ancestors too, and can move the page
} else {
    jumpBtn.hidden = false;
    jumpBtn.textContent = `${++unread} new messages ↓`;
}

Also worth knowing: overflow-anchor is on by default in Chromium and will fight a manual autoscroll on a list that grows at the bottom. If entries jitter, set overflow-anchor: none on the scroll container.
